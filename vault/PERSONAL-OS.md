# Personal OS

This folder is a file-based personal operating system, run by an AI assistant using the `personal-os` skill.

**AI agents: start here.**
1. Read `PROFILE.md` (who the user is, life areas, settings).
2. Read `ops/reference/commands-detail.md` before running any planning command you haven't run this session.
3. Never edit anything in `journal/` — it belongs to the user.
4. Read before you write; respect `[LOCK]`, `[KILL]` and `[?]` markers (see `ops/reference/edit-provenance-sop.md`).

**Humans:** write your tasks in today's journal (`journal/Journal YYYY-MM-DD.md`) under `## Tasks`, then ask your assistant for a `daily plan`, `weekly plan`, or `weekly review`.
